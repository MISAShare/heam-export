# HEAM Report Export

صفحة تصدير تقارير لوحة متابعة أعمال مكتب سعادة عبد الله بن زرعه.

- تُفتح من زر «تصدير التقرير» في لوحة المتابعة (Power BI).
- بيانات التقرير تُمرَّر داخل الرابط بعد علامة `#` ولا تُرسَل إلى خادم GitHub؛ يُبنى التقرير ويُنزَّل داخل متصفح المستخدم.
- الصفحة لا تحمّل أي مكتبة من الإنترنت؛ مكتبات PDF وPowerPoint (jsPDF، PptxGenJS، html-to-image) مضمّنة في الملف نفسه.
- الرابط المتوقع: https://misashare.github.io/heam-export/
